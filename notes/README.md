# 笔记

按领域分目录，一个主题一个文件。文件名就是这个主题的名字，中文即可。

| 目录 | 放什么 |
|---|---|
| `cs/` | 计算机：操作系统、网络、编程语言、工具链、算法 |
| `math/` | 数学：微积分、线代、概率、离散 |
| `english/` | 英语：词汇、语法、写作 |
| `misc/` | 其他领域，以及不属于任何学科的思考 |

## 和日志的分工

日志记「我今天做了什么」，笔记记「这件事我搞明白了」。

同一个主题可以先在日志里滚几周，等真能从头讲清楚了，再单独成篇放到这里。不要一上来就建笔记文件——那样往往只写了个标题。

新领域直接建目录，不用改任何配置。
