# 学习记录

记录**学过什么、想通了什么、卡在哪里**。不挑领域，靠目录区分。

> 写给自己半年后回看。所以宁可是流水账，也不要空着。

---

## 三种记录，粒度不同

| 类型 | 位置 | 什么时候写 | 篇幅 |
|---|---|---|---|
| **日志** | `log/YYYY-MM.md` | 每次学完当天，或第二天补 | 5–15 行，允许流水账 |
| **笔记** | `notes/<领域>/` | 某个主题真正想清楚了 | 不限，目标是能给别人看懂 |
| **项目** | `projects/` | 动手做出来、能跑的东西 | 附 README + 截图 |

**日志是原料，笔记是成品，项目是证据。** 三者不必都写，但至少要有日志——不然一周后就记不清当时在纠结什么了。

---

## 目录

```
learning-log/
├─ log/            按月一个文件，追加式记录
├─ notes/          按领域沉淀的笔记
│  ├─ cs/          计算机：系统、网络、语言、工具链
│  ├─ math/        数学：微积分、线代、概率、离散
│  ├─ english/     英语：词汇、语法、写作
│  └─ misc/        其他领域，以及不属于任何学科的思考
├─ projects/       动手做的东西，一个子目录一个项目
└─ templates/      记录模板，复制着用
```

新领域直接建目录，不需要改任何配置。

---

## 写作约定

- **日期一律 `YYYY-MM-DD`**，按日期排序才不会乱
- **目录名用小写英文，文件名可以用中文**——目录是结构，文件名是内容
- 一条日志 = 一个 `##` 小节，标题格式 `## 2026-10-18 · 主题`
- 引用别人的内容要**给链接**，不要只写「网上看到的」
- 代码块标语言，图片放大图床或用相对路径 `assets/`

---

## 日志怎么写

复制 `templates/daily.md`，四栏固定：

**做了什么** / **想通了什么** / **还没懂** / **下一步**

其中「**还没懂**」这一栏最重要。它是下次学习的入口，也是半年后最值钱的东西——你会发现自己反复卡在同一类问题上。

## 这个仓库不做什么

- **不放课程资料、教材 PDF、别人的笔记原文**——版权问题，而且对自己没有增益
- **不放几百 MB 的图片或数据集**——仓库撑大后 `clone` 会失败，等于废了
- **不为刷贡献图而提交**——空 commit 反而减分
